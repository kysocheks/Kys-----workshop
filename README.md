# KySочек Workshop

Витрина мастерской: сайты, игры, код.

## Команды

```bash
npm install
```

```bash
npm run dev
```

```bash
npm run validate
```

`validate` прогоняет типы → линтер → контраст → сборку.

| Скрипт | Что делает |
| --- | --- |
| `npm run dev` | Сервер разработки на :3000 |
| `npm run build` | Продакшен-сборка |
| `npm run typecheck` | `tsc --noEmit`, строгий режим |
| `npm run lint` | ESLint |
| `npm run contrast` | Контроль контраста всех подкрашенных комнат |

> **Не запускайте `build`, пока работает `dev`.** Они делят папку `.next`, и
> сборка выбивает у сервера разработки куски, которые он держит в памяти.
> Результат — `Cannot find module './271.js'` и белый экран. Лечится
> остановкой сервера, удалением `.next` и повторным `npm run dev`.

## Как устроено

### Один источник правды

`lib/works.ts` держит все работы, палитры и адреса. Больше нигде в коде нет ни
одного цвета проекта и ни одной ссылки.

Опубликовали работу на Vercel — вписали адрес в `href`. Одна строка.
Появились кадры — положили файлы в `public/shots/<slug>/` и перечислили в
`shots`. Больше ничего трогать не нужно.

### Комната подкрашивается под экспонат

Workshop — самостоятельный сайт со своим лицом: холодный графит и сурик,
цвет, которым чертёжник правит по готовому. Ни один экспонат такого акцента не
использует, поэтому мастерская узнаётся всегда.

Пока витрина работ перед глазами, комната **подкрашивается** под открытую
работу. Акцент перенимается целиком — это опознавательный знак. Фон и
поверхность сдвигаются едва-едва, чернила почти не трогаются. Ушли из витрины —
Workshop возвращает собственный вид.

Светлые работы (CHROMA, PRISM RIOT) тянут комнату вполсилы: на полной тяге
графит уезжает в мутно-серое.

### Почему цвет перетекает, а не переключается

Обычная переменная стилей — просто строка, и браузер не умеет её плавно
менять. Пять цветов объявлены через `@property` с типом `<color>`, поэтому
браузер знает, что там настоящие цвета, и интерполирует их. Палитра ставится на
корень документа, а не на внутреннюю обёртку — иначе фон страницы и системные
полосы прокрутки остаются от старой темы.

Линии и заливки не хранятся отдельно: они выводятся из чернил и акцента через
`color-mix`, поэтому перетекают следом сами, а цвет нигде не задан дважды.

### Контраст меряется, а не прикидывается

Комната меняет цвет под каждую работу — значит каждый её вариант надо
проверять отдельно. Глазом такое не ловится: провал до 3:1 выглядит «просто
чуть бледнее», а читать это уже нельзя.

`npm run contrast` считает все пары во всех комнатах и падает, если хоть одна
не берёт порог: 7:1 для основного текста, 4.5:1 для второстепенного и акцента.
Меряется по худшему случаю — по самой светлой поверхности, на которую цвет
вообще ложится.

Цвета, которые порог не берут, **осветляются, а не ограничиваются по размеру**.
Синий акцент PRISM RIOT давал 2.33:1 — подписи в одиннадцать пикселей таким
цветом нечитаемы, поэтому он поднят до порога с сохранением оттенка.

## Стек

| Пакет | Зачем |
| --- | --- |
| Next 15 (App Router) | Статическая отрисовка, самостоятельная раздача шрифтов |
| React 19 + TypeScript 5.9 (строгий) | `noUncheckedIndexedAccess`, `noUnusedLocals`, `verbatimModuleSyntax` включены |
| Tailwind 4 | `@theme` держит токены; типографика написана руками, а не набрана утилитами |
